### Used technologies:
**Frontend**
 - Vue.js (Options API)
 - Vuex
 - Vue-Router
 - GoogleMaps
 - Vuetify
 - Swiper
 - YUP

**Backend:**
- Node.js (Express.js)
- MongoDB + mongoose

## How to run the project

Use this command from the /frontend folder

**npm run serve**

### To start backend part:

Use this command from the /backend folder

**npm run server**
